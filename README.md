# Исходники демонстрационного интерфейса

HTML, CSS и JavaScript без фреймворков и без установки зависимостей.

## Запуск

Распакуйте архив. Откройте index.html в браузере.
Для работы API буфера обмена удобнее запустить локальный сервер:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000.
На Windows также можно использовать `py -m http.server 8000`.

## Файлы

- index.html — структура приложения.
- style.css — оформление, адаптивность, переворот документов.
- app.js — вкладки, поиск, свайп карточек, QR-сторона, модальные окна.
- assets/ — изображения, QR-код, иконка сайта и шрифт.

Реализованы лента, четыре карточки документов, плавная карусель с управлением пальцем и мышью, переворот єДокумента, поиск сервисов и меню. Карусель также поддерживает клавиши стрелок.

Карточки имеют видимую пометку «ДЕМО — не є документом» на обеих сторонах. QR-код содержит только сообщение о демонстрационном интерфейсе; он не подтверждает личность. Государственные функции, проверка документов, подписи и серверная часть отсутствуют.

Шрифт e-Ukraine Regular: https://thedigital.gov.ua/fonts. Авторство: Dmytro Rastvortsev / Fedoriv Agency. Лицензия: Creative Commons Attribution 4.0. Фото и баннер взяты из скриншотов, предоставленных пользователем. SVG-иконки интерфейса воссозданы вручную.

Фон документов медленно переливается даже без свайпа, плавно смешивает палитры при движении карточек и при перевороте на QR-сторону. Учитывается настройка уменьшения анимации в системе.
